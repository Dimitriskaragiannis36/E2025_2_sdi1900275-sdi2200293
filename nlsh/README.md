Σκοπός της εργασίας είναι η κατανόηση και εφαρμογή σύγχρονων μεθόδων ευρετηρίασης υψηλοδιάστατων δεδομένων, η υλοποίηση του αλγορίθμου σε Python, καθώς και η αξιολόγηση της απόδοσής του ως προς ταχύτητα, ακρίβεια και ποιότητα προσέγγισης σε σύγκριση με τους κλασικούς αλγορίθμους εύρεσης κοντινότερων γειτόνων. Χρησιμοποιείται το εκτελέσιμο της 1ης ΕΡΓΑΣΙΑΣ και Python 3 (Python 3.10+) σε σύστημα Linux.



### α) Περιγραφή προγράμματος

Το πρόγραμμα υλοποιεί έναν σύγχρονο μηχανισμό Neural Locality-Sensitive Hashing (Neural LSH) για προσεγγιστική αναζήτηση πλησιέστερων γειτόνων (Approximate Nearest Neighbor Search – ANN) πάνω σε σύνολα υψηλοδιάστατων δεδομένων MNIST και SIFT.
Η υλοποίηση χωρίζεται σε δύο εκτελέσιμα:


## 1. nlsh_build.py – Κατασκευή Ευρετηρίου (Index Building)

Το πρόγραμμα κατασκευάζει το ευρετήριο Neural LSH μέσω των παρακάτω βημάτων:

- Κατασκευή k-NN γράφου με Ευκλείδεια απόσταση και βάρη (2 για αμοιβαίους γείτονες, 1 για μονόπλευρους).

- Ισοκατανεμημένη διαμέριση του γράφου με το KaHIP, ώστε τα δεδομένα να ομαδοποιηθούν σε m blocks.

- Εκπαίδευση MLP ταξινομητή (PyTorch) για την πρόβλεψη του block κάθε διανύσματος.

Μετά την ολοκλήρωση, αποθηκεύονται:

- Το εκπαιδευμένο νευρωνικό μοντέλο (model.pth)

- Το inverted index, δηλαδή οι λίστες αντιστοίχισης blocks → σημεία



## 2. nlsh_search.py – Εκτέλεση Προσεγγιστικής Αναζήτησης

Για κάθε query vector q, εκτελούνται:

- Πρόβλεψη block από το MLP μέσω softmax

- Multi-probe επιλογή των T πιθανότερων blocks

- Συλλογή υποψηφίων μόνο από τα επιλεγμένα blocks

- Ακριβής αναζήτηση στους υποψηφίους με Ευκλείδεια απόσταση για την εύρεση των Ν πλησιέστερων γειτόνων

Έτσι επιτυγχάνεται σημαντική επιτάχυνση σε σχέση με εξαντλητική αναζήτηση.


## Υποστηριζόμενοι τύποι αναζητήσεων

Το πρόγραμμα υποστηρίζει:

- 1-NN αναζήτηση

- k-NN αναζήτηση

- Range search εντός ακτίνας R


## Μετρικές εξόδου

Για κάθε query καταγράφονται:

- # Οι N προσεγγιστικοί πλησιέστεροι γείτονες και οι αποστάσεις τους

- # Η πραγματική απόσταση του q από τον ακριβή NN (brute-force)

- # R-near neighbors (όταν γίνεται range search)

- # Average Approximation Factor (AF)

- # Recall@N

- # Queries Per Second (QPS)

- # Μέσος χρόνος προσεγγιστικής αναζήτησης

- # Μέσος χρόνος ακριβούς αναζήτησης (brute-force)


## Πειραματική αξιολόγηση

Η μελέτη περιλαμβάνει:

Εξερεύνηση βέλτιστων υπερπαραμέτρων (layers, nodes, batch size, epochs, k, m, T κ.λπ.)

Σύγκριση Neural LSH με μεθόδους της Εργασίας 1:
LSH, Hypercube, IVFFlat, IVFPQ

Αξιολόγηση ως προς:
AF, Recall@N, χρόνους αναζήτησης

python3 nlsh_build.py     -d data/sift/input.dat     -i nlsh_index/sift     -type sift     --knn 2     -m 100     --imbalance 0.03   --kahip_mode 2  --layers 3  --nodes 64    --epochs 10  --batch_size 128  --lr 0.001  --seed 1
